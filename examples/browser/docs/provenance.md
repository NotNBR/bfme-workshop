# Content provenance

The JavaScript game, renderer, Python adapter and tests were newly written for this prototype. No Open-BFME-2, BAR, Supreme Commander, Godot or Recoil implementation source was copied into this repository.

`../openbfme2` was inspected as a read-only technical reference. The research document identifies the recovered group-command and camera files used to understand system boundaries. Open-BFME-2 has its own GPL license; this prototype does not represent its binary reconstruction as complete.

`local/content/bfme-content.json` and `local/content/portraits/*.png` are generated from the user's existing BFME2 installation. These are excluded from Git. Their original rights remain with their respective owners; this project does not grant permission to redistribute the retail content. A clean checkout uses approximate unit values and schematic graphics until the user runs the importer on a local installation.

Names, faction references and imported portraits identify the original game content. This is an unofficial local prototype and is not affiliated with the original publishers or rights holders. No BFME/Supreme Commander executables, model archives, music or videos are included in the repository.

The imported JSON records the source archive hash and individual object/weapon paths. Missing fields intentionally remain prototype defaults; the menu's local-content badge does not imply complete retail behavior or balance fidelity.
